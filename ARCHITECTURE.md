## Key Data Flows

### Live Data (primary path)
```
Page component
  → useLiveData(areaId, year)        [src/hooks/useLiveData.ts]
    → SWR → GET /api/live-data/[areaId]
      → getLiveDemographicsData()    [src/lib/data/live-data.ts]
         getABSCacheEntry(lgaCode, 'G01')   ← SQLite abs_cache
         getABSCacheEntry(lgaCode, 'G02')   ← SQLite abs_cache
         ... (G33, B31_2011, G36, G51, G46, G15, G49, G49_2016, SEIFA, LABOUR, ERP)
         getNSWProjection(lgaName)          ← SQLite nsw_projections
         getTransportStaticForLGA(lgaName)  ← SQLite transport_static
         getLiveTfNSWTransportData(areaId)  ← TfNSW traffic API + crash workbook + patronage-source detection
         field-by-field fallback to sample-data.ts if SQLite row missing
      → { data: XxxData, meta: DataMeta }
         meta.liveFields / meta.sampleFields show which fields are live
  → Page renders DataSourceBadge with meta
```

### Seeding the SQLite Cache
```
CLI: npm run seed [--static] [--abs] [--lga id]
  → scripts/seed-db.ts
    --static: reads nsw-projections-data.ts + nsw-employment-projections.ts + tfnsw-transport.ts
              → upserts into nsw_projections + transport_static tables
    --abs:    iterates LGA_CODE_MAP, calls fetchAllABSDataForLGA(lgaCode) for each
              → fetchG01, fetchG02, fetchG33, fetchB31_2011, fetchG36, fetchG51, fetchG46, fetchG15,
                fetchG49, fetchG49_2016, fetchSEIFA, fetchLabour, fetchERP
              (13 SDMX-ML XML requests per LGA, plus historical JTW tables)
              → upserts into abs_cache table

Admin API: POST /api/admin/refresh { mode, lgaId }  (admin auth / ADMIN_KEY)
  → enqueue persisted refresh job
  → worker / inline runner executes via src/lib/seed-runner.ts
```

### NSW Excel Projections (manual upload path)
```
/upload → ProjectionUploadPanel
  → parseNSWProjectionsExcel(arrayBuffer)   [src/lib/excel-parser.ts]
    → match LGA names via LGA_MAPPING
  → useProjectionStore.setProjections()
    → localStorage.nsw_population_projections
  → available in any page via useProjectionStore()
  (Also upserted into nsw_projections SQLite table for use by live-data layer)
```

## SQLite Schema (`data/cache.db`)
| Table | Unique key | Purpose |
|---|---|---|
| `abs_cache` | `(lga_code, dataset)` | Parsed ABS Census / ERP data per LGA |
| `nsw_projections` | `(lga_name, projection_type)` | Population & employment projections |
| `transport_static` | `(lga_name, year)` | TfNSW mode share / commute metrics |
| `tfnsw_cache` | `(lga_code, dataset)` | GTFS coverage, live traffic trends, crash summaries, patronage source metadata |
| `app_config` | `key` | Key-value store (e.g. `abs_last_seeded`) |
| `refresh_log` | `id` | Audit log of seed runs |

## ABS Fetcher Details (`src/lib/abs-fetchers.ts`)
- **Format**: SDMX-ML (XML) — `Accept: application/xml`
- **Auth**: None required; needs `User-Agent: Mozilla/5.0` (CloudFront blocks bot UAs)
- **Base URL**: `https://data.api.abs.gov.au/rest/data`

| Function | Dataset ID | Dimensions used |
|---|---|---|
| `fetchG01Population` | C21_G01_LGA | SEXP |
| `fetchG02Medians` | C21_G02_LGA | MEDAVG (1=age, 2=hh_income, 3=mortgage, 6=rent, 8=avg_hhd_size) |
| `fetchG33DwellingStructure` | C21_G36_LGA | DWTSTRD (11=sep house, 2=semi, 3=flat, 9=other) |
| `fetchB31_2011` | ABS_CENSUS2011_B31_LGA | STRD (1=house, 2=semi/townhouse, 3=flat/apartment, 9=other) |
| `fetchG36TenureType` | C21_G37_LGA | TENLLD (1=owned, 2=mortgage, 3=rented) |
| `fetchG51Industry` | C21_G53_LGA | INDP (ANZSIC A–S letter codes) |
| `fetchG46SchoolCompletion` | C21_G16_LGA | HSCP (1=Yr12 … 6=none) |
| `fetchG15SchoolAttendance` | C21_G15_LGA | TYSTAP (preschool, primary, secondary, vocational, university) |
| `fetchG49Qualifications` | C21_G49_LGA | QALLP (1=postgrad, 3=bach, 51=adv_dip, 4=cert3/4) |
| `fetchG49_2016` | ABS_C16_G49_LGA | OCCP_C16=Z × SEX_ABS=3 × QALLP_C16 (historical qualification trend) |
| `fetchSEIFA` | ABS_SEIFA2021_LGA | SEIFAINDEXTYPE × SEIFA_MEASURE=SCORE |
| `fetchLabour` | C21_G46_LGA | LFSP (1=FT emp, 2=PT emp, 4=unemp, 5+=NILF) |
| `fetchERP` | ABS_ANNUAL_ERP_LGA2021 | LGA_2021 × SEX_ABS=3 × AGE=TOT |
| G55 (journey-to-work) | — | **No SDMX endpoint at LGA level — stubbed null** |

## LGA Coverage
128 NSW LGAs in `LGA_CODE_MAP` (all 10 NSW regions) + `benchmark_gsy` (1GSYD) + `benchmark_nsw` (1NSW).
Regions: Greater Sydney (33) · Hunter (9) · Central Coast (1) · Illawarra-Shoalhaven (5) · South East & Tablelands (8) · New England & North West (12) · North Coast (13) · Central West & Orana (19) · Riverina-Murray (19) · Far West (8)
Key codes: `lga_sydney→17200` `lga_parramatta→16260` `lga_blacktown→10750` `lga_newcastle→15900` `lga_wollongong→18450`
Actual seeded coverage depends on the current cache contents in `data/cache.db`; use the admin panel or DB queries to verify what is populated locally.
